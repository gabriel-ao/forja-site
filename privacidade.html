Política de Privacidade

Última atualização: 20 de novembro de 2026

1. Quais dados a Forja usa

Quando o usuário conecta uma conta do TikTok, a Forja recebe do TikTok, com a autorização do usuário:

  • o identificador da conta (open_id), o nome de usuário e o apelido públicos;
  • os tokens de acesso necessários para publicar vídeos em nome do usuário (permissões user.info.basic e video.publish).

A Forja não recebe nem guarda a senha do TikTok, e não lê mensagens, seguidores ou outros dados da conta.

2. Para que os dados são usados

Somente para mostrar ao usuário qual conta está conectada e para publicar os vídeos que o próprio usuário agendou, com a legenda e a privacidade que ele escolheu.

3. Onde os dados ficam

A Forja roda no computador do próprio usuário. Os tokens do TikTok ficam guardados nesse computador, cifrados (AES-256-GCM). Os vídeos e cortes também ficam no computador do usuário e só são enviados ao TikTok no momento da publicação que o usuário agendou.

4. Compartilhamento

A Forja não vende nem compartilha dados com terceiros. Os vídeos são enviados apenas ao TikTok, pelas APIs oficiais, quando o usuário agenda uma publicação.

5. Como apagar os dados

O usuário pode desconectar a conta a qualquer momento na Forja (botão "Desconectar"), o que apaga os tokens guardados. Também é possível remover o acesso nas configurações do TikTok, em Segurança → Gerenciar permissões de apps.

6. Contato

Pedidos e dúvidas sobre privacidade: github.com/gabriel-ao/forja-site/issues

Privacy Policy

Last updated: November 20, 2026

1. Data Forja uses

When a user connects a TikTok account, Forja receives from TikTok, with the user's authorization:

  • the account identifier (open_id), public username and display name;
  • the access tokens needed to publish videos on the user's behalf (scopes user.info.basic and video.publish).

Forja does not receive or store the TikTok password, and does not read messages, followers or other account data.

2. How data is used

Only to show the user which account is connected and to publish the videos the user scheduled, with the caption and privacy level the user chose.

3. Where data is stored

Forja runs on the user's own computer. TikTok tokens are stored on that computer, encrypted (AES-256-GCM). Videos and clips also stay on the user's computer and are only sent to TikTok when a post the user scheduled is published.

4. Sharing

Forja does not sell or share data with third parties. Videos are only sent to TikTok, through its official APIs, when the user schedules a post.

5. Deleting data

Users can disconnect their account at any time in Forja ("Disconnect" button), which deletes the stored tokens. Access can also be removed in TikTok's settings under Security → Manage app permissions.

6. Contact

Privacy requests and questions: github.com/gabriel-ao/forja-site/issues
